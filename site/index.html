Questions worth asking.

Is this a penetration test?

No. It is static analysis plus a manual code review. We do not attack live systems or prove exploitability. The report states this limitation instead of hiding it.

Will my code leave my machine?

The free scanner runs entirely offline. For a paid audit you share the repo or a zip; it is deleted after 30 days and never used to train models.

What if you find nothing?

You pay nothing. If we miss a critical issue that a reasonable review of the agreed scope should have caught, your next audit is free.

Do you need production access?

No. A repo, the MCP config, and a short description of the deployment are enough. Live testing is a separate engagement and requires written authorization.

Can you fix the code too?

Yes, as a separate scope. The audit includes concrete remediation guidance either way.
